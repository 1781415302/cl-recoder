## 调度与前置信息

每个评审获得用户的九节 SDD 要求、7 个已确认缺陷、当前工作树为基线、不得新增依赖或无关重构、自包含合同/Stage验收要求、只读和 Windows pwsh 约束。没有让子代理脱离需求评价任意产品方案，也没有委派它们实现代码。

所有子代理只返回事实与定位，最终文档修改由主 Agent 独立复核后执行。未触碰真实采集器、数据库、计划任务或 UAC。

## 主 Agent 收尾复核

1. 关键私有状态也写成完整类型定义：Engine held为来源/扫描码二元组集合，AppTimeLedger为day/exe Duration余数表，避免下游拿到无字段的概念类型。
2. 明确时间集成测试同时控制Instant和墙钟端点，禁止假注入而保留真实Local::now；不指定显然的方法体写法。
3. S5保护断言覆盖六张统计表及meta，而不是只看按键总数；来源准备失败且目标不存在才断言不建文件。
4. Collector crate没有直接rusqlite依赖。S4失败flush回归不得为测试加依赖或修改store，可在临时Aggregator输入桶注入不存在device_id使既有外键事务失败，核查app整秒桶回并与ledger不重复提取；清除该测试标记后再次flush。这是可选实现手法，合同只锁失败回滚行为。
5. 本轮只新增设计与裁决文档；没有修改项目源代码。实施Plan列出的测试是未来verify关卡，不能把文档评审通过写成实现已经通过这些关卡。
